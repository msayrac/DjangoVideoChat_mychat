# Build a Video Calling Website with Django & Agora SDK
This is a real-time video calling application built with Django for the backend and Agora Video Web SDK for the WebRTC functionality. The application supports group and peer-to-peer video calls with essential meeting controls.

## Features
* Group Video Calling: Join rooms with multiple participants using a unique room name.
* Toggle Camera (On/Off)
* Mute/Unmute Microphone
* Leave Room functionality
* Dynamic Token Generation: Securely generate Agora RTC tokens using a Django backend.
* User Identification: Display usernames on top of video streams.
* Responsive UI: Optimized for both desktop and mobile devices.
* Persistence: Participant data is managed via Django models and identified using unique UIDs.

## Tech Stack
* Backend: Python, Django
* Frontend: JavaScript (ES6+), HTML5, CSS3
* Video Engine: Agora RTC SDK (Web)
* Authentication: Agora Token Service (RtcTokenBuilder)
